# Diccionario de datos

| Campo | Tipo | Descripción | Sensibilidad |
|---|---|---|---|
| customer_id | string | Identificador técnico | Identificador |
| age | integer | Edad del cliente | Dato de contexto |
| monthly_spend | float | Gasto mensual | Financiero sintético |
| tenure_months | integer | Antigüedad | Dato operativo |
| support_calls | integer | Número de llamadas | Dato operativo |
| region | string | Región sintética | Contexto |
| churn | integer | Variable objetivo | Modelo |

Todos los datos del conjunto son sintéticos y se utilizan exclusivamente para fines pedagógicos.
